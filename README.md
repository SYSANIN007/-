# 💳 ACID Wallet — учебное Android-приложение на Kotlin

Мобильный «кошелёк», в котором **ACID** и **CRUD** не просто упомянуты в комментариях,
а работают и **демонстрируются кнопками**: приложение умеет специально ломать инварианты
и показывать, что при этом происходит с базой.

* **Kotlin** + **Jetpack Compose** (Material 3)
* **Room / SQLite** — настоящие транзакции (`BEGIN … COMMIT / ROLLBACK`), режим WAL
* Никаких сетевых запросов — всё локально, запускается на эмуляторе и на телефоне

---

## 1. Как открыть и запустить (Android Studio)

1. **Установите Android Studio** (Ladybug 2024.2.1 или новее). JDK 17 идёт в комплекте,
   отдельно ставить ничего не нужно.
2. **File → Open…** и выберите **корневую папку проекта** (ту, где лежит `settings.gradle.kts`
   и этот README). Нужно открывать именно папку проекта, а не отдельный файл.
3. Дождитесь **Gradle Sync**. Android Studio сама скачает Gradle 8.9
   (адрес указан в `gradle/wrapper/gradle-wrapper.properties`), плагин Android Gradle Plugin,
   Compose, Room и KSP. Нужен интернет — примерно 300–500 МБ на первый раз.
   *Если Studio предложит установить SDK Platform 35 — согласитесь.*
4. Подключите телефон (Android 8.0 / API 26 и выше) или создайте эмулятор
   (**Device Manager → Create Device → Pixel 6 / API 34–35**).
5. Нажмите зелёную кнопку **▶ Run 'app'** (Shift+F10).

При первом запуске база создаётся автоматически и наполняется демо-данными:
три счёта (карта, копилка, наличные) и служебные счета для ACID-экспериментов.

> **Про `gradlew` в этом репозитории.** Бинарный `gradle/wrapper/gradle-wrapper.jar`
> в git не хранится (бинарники в репозиториях не нужны), поэтому рядом лежит
> скрипт-обёртка: он либо вызывает Gradle из `PATH`, либо сам скачивает нужную версию.
> Для Android Studio это не важно — IDE всегда скачивает дистрибутив по адресу из
> `gradle/wrapper/gradle-wrapper.properties`.
> Если очень нужна классическая обёртка: `gradle wrapper --gradle-version 8.9`
> (при установленном локально Gradle).

**Сборка из терминала** (после Gradle Sync, когда `ANDROID_HOME` настроен):

```bash
./gradlew assembleDebug        # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew installDebug         # сразу поставить на подключённое устройство
./gradlew test                 # юнит-тесты (JVM)
./gradlew connectedAndroidTest # инструментальные тесты (нужен эмулятор/телефон)
```

## 2. Что нажимать: четыре вкладки

### 🏠 Кошелёк — полный CRUD

| Буква | Что делает | Где в коде |
|-------|------------|------------|
| **C**reate | «Новый счёт»: INSERT счёта + системная запись «Начальный остаток» в одной транзакции | `WalletRepository.createAccount()` |
| **R**ead | Карточки счетов и журнал: `@Query` + `@Relation`, всё на `Flow` (UI обновляется сам) | `WalletDao.observeAccountsWithOperations()` |
| **U**pdate | Правка счёта, правка операции, «Отменить операцию», «Сверка журнала» | `updateAccount`, `updateOperation`, `cancelOperation`, `recalculateBalances` |
| **D**elete | Удаление операции (с корректировкой баланса) и счёта (журнал уходит каскадом) | `deleteOperation`, `deleteAccount` |

На каждой карточке счёта видно проверку инварианта:
`баланс = начальный остаток + Σ операций журнала` — свойство **C** в живом виде.

### 📒 Журнал — READ с фильтрами

Поиск по комментарию и фильтры по счёту, типу и статусу. Фильтры подставляются
**внутрь SQL-запроса** (`observeOperationsFiltered`), а не фильтруют список в памяти.

### 🔐 ACID — теория и эксперименты

* **A · Atomicity** — кнопка запускает три шага на служебном счёте:
  1) корректная транзакция → COMMIT; 2) тот же код **без** транзакции с падением в середине →
  «полуприменённое» состояние и сломанный инвариант; 3) сбой **внутри** транзакции → ROLLBACK.
* **C · Consistency** — три инварианта и кнопка «Проверить инварианты сейчас»:
  пересчёт балансов по журналу одной транзакцией.
* **I · Isolation** — кнопка запускает 4 опыта: чтение без транзакции, чтение внутри транзакции,
  потерянное обновление и его исправленная версия.
* **D · Durability** — режим журнала WAL и «отметка долговечности»: нажмите кнопку, полностью
  закройте приложение, откройте снова — отметка на месте.

### 🏦 Демо-банк — живые опыты на своих счетах

* «+1 000 ₽» / «−500 ₽» — одна транзакция: баланс + запись в журнале.
* «Перевод 500 ₽ (атомарно)» — списание и зачисление в одной транзакции.
* «⚠ Разорванный перевод 300 ₽» — антипример: две транзакции на одну операцию и сбой между ними.
  Смотрите на строку «Сумма A + B»: деньги «зависают» между счетами, пока вы не проведёте компенсацию.
* «20 параллельных переводов по 1 ₽» — стресс-тест изоляции: 20 настоящих транзакций одновременно,
  сумма по счетам не меняется, ни одна половинка перевода не теряется.

## 3. Как устроено (карта кода)

```
app/src/main/java/com/example/acidwallet/
├── MainActivity.kt                 # точка входа: Compose + тема
├── data/
│   ├── local/
│   │   ├── Entities.kt             # таблицы accounts и operations (FK + CASCADE)
│   │   ├── Converters.kt           # enum ↔ TEXT для Room
│   │   ├── WalletDao.kt            # CRUD: @Insert / @Query+@Relation / @Update / @Delete
│   │   ├── DemoDaos.kt             # живые наблюдения (Flow) и «элементарные» запросы для опытов
│   │   └── AppDatabase.kt          # SQLite + WAL + PRAGMA foreign_keys = ON
│   ├── DemoSeeder.kt               # демо-данные (вставляются одной транзакцией)
│   └── WalletRepository.kt         # вся бизнес-логика: каждая операция = одна транзакция
├── domain/
│   ├── Money.kt                    # деньги = Long в копейках, формат и разбор (ru)
│   └── Errors.kt                   # ошибки бизнес-логики и «сбой шлюза» для опытов
├── demo/
│   ├── AtomicityLab.kt             # COMMIT / половинчатое состояние / ROLLBACK
│   ├── IsolationLab.kt             # 4 опыта с гонками
│   ├── LiveDemos.kt                # отчёты «разорванного перевода» и стресс-теста
│   └── Reports.kt                  # модели протоколов экспериментов
└── ui/
    ├── WalletViewModel.kt          # состояние экранов + вызовы репозитория
    ├── AcidWalletApp.kt            # каркас: 4 вкладки, snackbar, индикатор операций
    ├── screens/                    # Wallet / Journal / AcidLab / DemoBank
    ├── components/                 # карточки, блоки кода, диалоги, отчёты
    ├── Format.kt                   # даты в русском формате
    └── theme/Theme.kt              # тёмная/светлая тема, цвета ACID-свойств
```

### Ключевые файлы для защиты работы

1. **`WalletRepository.transfer()`** — эталонная атомарная операция:
   списание, две записи журнала и зачисление в одном `db.withTransaction { }`.
2. **`WalletRepository.brokenTransfer()`** — тот же перевод, но разорванный на две транзакции:
   антипример, который можно запустить и увидеть последствия.
3. **`AtomicityLab.run()`** — три шага с измерениями: сколько строк журнала записано,
   на сколько изменился баланс, сошёлся ли инвариант.
4. **`WalletDao`** — все четыре буквы CRUD в одном интерфейсе.

## 6. Частые вопросы

**Нужен ли интернет при работе приложения?** Нет. Сеть нужна один раз — чтобы Android Studio
скачала Gradle и библиотеки. База локальная (SQLite).

**Где посмотреть базу?** В Android Studio: **View → Tool Windows → App Inspection → Database Inspector**
(работает на API 26+). Там видно таблицы `accounts` и `operations` и можно выполнять SQL вручную.

**Что если я всё сломал кнопками?** Вкладка «Кошелёк» → «Сбросить демо-данные»: база
очищается и наполняется заново одной транзакцией.

**Почему деньги в копейках (`Long`), а не в `Double`?** Потому что `0.1 + 0.2 != 0.3`,
и копейки «уезжают». Подробнее — в [`docs/ACID.md`](docs/ACID.md).

**Это приложение для реальных денег?** Нет. Это учебный проект: он создан, чтобы показать,
как работают транзакции, инварианты и изоляция. Никаких реальных платёжных систем здесь нет.
